## Current Issue: Lambda Timeout

**Problem:** Lambda times out after 5 minutes, but agent takes longer

**What's Working:**
- ✅ Code generation
- ✅ S3 structure
- ✅ Configuration passing

**What Times Out:**
- ❌ Agent response (takes >5 minutes)
- ❌ Code execution

**Lambda Timeout:** 300 seconds (5 minutes) - this is the AWS Lambda maximum

---

## Solutions

### Option 1: Increase Lambda Timeout (Recommended)

AWS Lambda max timeout is 15 minutes. Update it:

```bash
aws lambda update-function-configuration \
  --function-name dev-spark-agent-wrapper \
  --timeout 900 \
  --region us-east-1
```

This gives the agent 15 minutes to complete.

### Option 2: Use Async Invocation

Invoke the Lambda asynchronously and check S3 for results:

```bash
# Invoke async
aws lambda invoke \
  --function-name dev-spark-agent-wrapper \
  --invocation-type Event \
  --payload '{"prompt":"your query"}' \
  /tmp/response.json

# Wait a bit
sleep 120

# Check S3 for recent sessions
aws s3 ls s3://spark-data-817323390093-us-east-1/ | tail -5
```

### Option 3: Check S3 Directly

Even when Lambda times out, the code is still saved to S3:

```bash
# List recent sessions
aws s3 ls s3://spark-data-817323390093-us-east-1/ | tail -10

# Check a specific session
SESSION_ID="fb328149-1a95-4755-aac6-9e8ea8dc685b"
aws s3 ls s3://spark-data-817323390093-us-east-1/$SESSION_ID/ --recursive

# Download the code
aws s3 cp s3://spark-data-817323390093-us-east-1/$SESSION_ID/${SESSION_ID}_code.py -
```
